Primary category rules:
- Assign exactly one primary category to each article.
- Use 2–4 specific tags for cross-cutting subjects.
- Do not create a new category for a single article.
- Categories are editorial groupings first. Do not publish thin category landing pages just to create URLs.
- Create an indexable category page only when it can provide a useful introduction and at least 3–5 substantial related articles.
- Keep existing article canonical URLs unchanged unless there is a separate migration plan with redirects and Search Console monitoring.

## 4. Article metadata standard

Every new article should have:
- A unique title and one clear H1.
- A stable, descriptive URL slug.
- Exactly one primary category and 2–4 relevant tags.
- A concise meta description written for the actual search intent.
- A useful cover image with descriptive alt text.
- Original publication date and a modified date only after a meaningful update.
- Language declaration and correct canonical URL.
- Article or BlogPosting structured data, author, publisher, and breadcrumb markup where appropriate.
- A short table of contents for long guides.
- Contextual internal links to related RGS articles and the Tools directory.
- External references that genuinely support the article.
- A practical example, original analysis, screenshots, or first-hand testing wherever possible.

## 5. Editorial and SEO rules

1. Research the SERP and search intent before writing. Do not assume a keyword has demand based on its wording alone.
2. Avoid multiple articles targeting the same intent. Expand or update an existing article when that is more useful than publishing a near-duplicate.
3. Write for Pearl River Delta manufacturers and export-oriented SMEs while using clear English where overseas search intent is relevant.
4. Distinguish verified data, first-hand observations, recommendations, and hypotheses.
5. Do not claim case-study results or customer outcomes without evidence.
6. Use category pages as useful topic hubs, not thin tag archives.
7. Keep the Tools page as a resource directory; explain tool combinations and step-by-step workflows in Blog articles.
8. Preserve existing article URLs and use internal links to connect pillar guides, supporting articles, and relevant tools.
